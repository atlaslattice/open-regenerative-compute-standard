## Credentialed forks

Public API registration is different from government-only authorization. Do not classify an HTTP 403 as proof that government access is required. A credentialed operator can add permitted ingestion through a private backend and publish only redistributable snapshots with source dates, hashes and unit/grade mappings. Never put API keys, session tokens or passwords in the HTML, public JSON, receipt URLs or git history. Keep restricted operational and personal records out of public forks. Space-Track terms need special redistribution review.

Each ingestion adapter should emit provider, exact dataset/version, retrieval timestamp, unit, transformation boundary, geographic coverage, quality/suppression flags, authentication class, content hash and failure receipt. A successful download is not a working simulator adapter; integration and validation remain separate.

Review `source_registry.json` for evidence and per-source unknowns, and `public_feed_probe_receipts.json` for actual environment tests.
