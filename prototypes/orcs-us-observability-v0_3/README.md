Run `python3 -m unittest discover -s . -v` (12 unit tests). Run `python3 fetch_public.py` only in a network-capable environment respecting provider terms. Responses are local snapshots with hashes; they do not constitute live operation or provider outages.

This version identifies 13 feed candidates/stubs, preserving 2026-10-13 successful snapshots for USGS earthquake, NOAA SWPC, NWS point metadata and FEMA declaration **as historical receipts**. Public NASA EONET wildfire, NWS alerts and CelesTrak catalog sources are *not* verified connected. Operator freight capacity, Space-Track and EIA registered API require permission/registration as applicable. Regional freight links and risk assessments remain unknown.

`exposure.py` accepts independently geo-located hazards and facility or transport-node coordinates. It returns **proximity review candidates** only, never asserts a closure or creates a transport-route edge. Example records are explicitly synthetic. Adjudication requires actual asset location, hazard footprint, time, severity, official alert, operator status and human review. A non-overlapping or absent event never guarantees safety.

`policy_scenarios.py` implements a nonbinding proposed gasoline affordability / reserves export-candidate gate. It is not legal export authorization and does not automatically direct private operations.

The first national petroleum corridor remains existing **Gulf Coast exports redirected to PADD1 imports** under confirmed grade/contract/capacity and lawful Jones Act terms, not Tyler refinery expansion.
