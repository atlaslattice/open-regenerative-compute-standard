## Evidence labels

MEASURED = source-linked dated observation. REPORTED = external documented claim. DERIVED = reproducible arithmetic. MODELED = assumption-based scenario. PROPOSED = unapproved design. UNKNOWN = evidence gap. QUARANTINED = not safe to treat as authority. NON-CANON and ZERO REALIZED CREDIT = no Atlas deployment or realized benefit verified.

Code testing never equals physical-site acceptance. Corporate partnership, regulatory approval, local adoption and field performance are never assumed.

## Historical material

Nothing has been erased from existing repositories. Legacy archives remain searchable and forkable where already public; their presence does not imply current scientific validity or authority. The objective is to guide readers to the current reviewed versions without destroying provenance. Private or sensitive materials require review before public release.
