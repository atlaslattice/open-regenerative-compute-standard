# ARC source receipt — v0.1

Primary: Sorbom et al., DOI 10.1016/j.fusengdes.2015.07.008. Version inspected: https://arxiv.org/pdf/1409.3540v2 (2015-08-16). Local PDF bytes hashed in ARC_TABLE11_RECEIPT_v0_1.json. The published journal version may round differently; do not mix values without a version receipt.

Table 11, PDF page 30: all 19 component/subtotal/total rows transcribed into ARC_TABLE11_v0_1.csv. PDF rendered and table visually inspected. REBCO tape is length 5730 km, mass approximately zero; the CSV uses UNKNOWN for its physical volume rather than converting length to volume.

Section 6.2, PDF page 29: fabrication estimate uses a mass-based $1.06M/tonne scaling in FY2014 USD, with exceptions where fabrication is set equal to material cost. It is a rough extrapolation, not a supplier quote. Section 6 explicitly says full reactor costing is outside the paper's scope.

Section 6.3, PDF page 31: divertor excluded from Table 11 because design was open; a separate rough estimate is $17.5M fabricated. Therefore the $92M vessel subtotal must not silently include that divertor, or be replaced with $35–75M as though the latter were a reproduced whole-vessel price.

Table 11 grand fabricated range $5.5–5.6B excludes balance-of-plant equipment. This is not a replacement for the recovered $2.8B chassis proxy and not a new full-campus CAPEX. The missing proxy ancestry is unresolved.

Source reproduction here means table transcription and arithmetic recovery. It does not validate the cost model, component lifetimes, reactor operation or D-D adaptation.

The reaction bookkeeping uses the primary engineering documentation https://ukaea.github.io/PROCESS/physics-models/fusion_reactions/plasma_reactions/ for reaction identities and rounded energies. Inputs such as power, availability, survival and recovery remain scenario assumptions. No evaluated cross-section/temperature source has been reproduced for this operating point.
