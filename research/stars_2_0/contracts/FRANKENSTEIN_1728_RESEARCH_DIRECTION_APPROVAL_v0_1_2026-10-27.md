## Approved direction

**Primary mathematical architecture:** 12 × 12 × 12 = **1,728** periodic lattice states, using the **TCSS** toroidal spectral system as the principal hypothesis / numerical implementation platform. This is a *research choice*, not evidence that 1,728 nodes are physically or operationally optimal.

Keep **three historically distinct source/operator lineages**:
1. **Original SHUGS:** original von Mangoldt / prime-smearing / zeta-zero-informed harmonic kernel; preserve original source values, index dependence, boundary conditions and reported failures.
2. **Element-145 HSUF:** separate historical 144+1 architecture; preserve admin-node source, Hanning window behavior and historical scores. **Do not silently import privileged administrator semantics** into TCSS.
3. **TCSS / Path B:** full 12³ toroidal state space, graph Laplacian baseline plus historical H_xp, L_z, X_z L_z terms *when recovered and source-qualified*. The existing 1,728-node Laplacian test is **not** full TCSS.

Build **fourth, explicitly new Frankenstein hybrid candidate** only after the three sources are separately tested, with source-traced component ablations, source-specific parameter names, and explicit topology/units mappings. Candidate hybrids should compare SHUGS harmonic couplings using original index distance against separate toroidal graph-distance and spectral-distance alternatives. Do not pretend a new distance metric reproduces the original source.

**Governance design constraint:** Decentralization is a project-lead preference. No obligatory single centralized scheduler, unilateral permission oracle, or mandatory administration node. Optional observer/registry roles must have explicit, testable failure semantics and distributed fallback; model actual network authority rather than claiming that GUE spacing measures governance quality.

## Accepted implementation and falsification plan

- **G0 / recover:** immutable original code/docs, hashes, historical numerical receipts, explicit finite-dimensional definitions for H_xp/L_z/X_z, sign conventions and Hermiticity/domain. Preserve missing definitions as NOT RECOVERED; no fabricated equivalent.
- **G1 / reproduce:** run unmodified SHUGS and Element-145 sources as A/A tests at their respective original sizes and configurations; compare to previous independent reconstructions, document any mismatch. Separately reproduce full TCSS 1,728-node Laplacian and its numerical fixtures.
- **G2 / direct source operators:** implement full TCSS only to the extent its original definitions are retrieved; source-incomplete terms remain blocked and candidate discretizations must be distinctly labeled. Compare Hermitian residuals, spectra, invariants, sensitivity and seeded ensembles.
- **G3 / hybrid A/B:** source-trace every addition; run ablations of each SHUGS/HSUF term, torus term, chiral term and boundary window. Compare at equal degrees of freedom and matched budgets where justified. Do not infer real-world physics or network throughput from GUE-KS.
- **G4 / applied validation:** separately test distributed-network throughput/failure tolerance (with implemented routing, control roles and workload) and bounded-material modal/stress prediction (with physical M,C,K, actuator/sensor maps and held-out measurements). A third lattice coordinate may denote spatial depth or other physical structure *only if derived and justified*, not imposed to suit analogy.
- **G5 / independent review:** publish new source and machine-readable receipts, positive and null results, uncertainty and alternatives; return for adversarial gap audit before promotion.
